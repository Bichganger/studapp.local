# Учеба24

Онлайн-платформа для образования.

## Запуск

1. Откройте `index.php`
2. Войдите или зарегистрируйтесь
3. Перейдите в кабинет

## Структура

- **admin/** — Администратор (7 страниц)
- **teacher/** — Преподаватель (6 страниц)
- **student/** — Студент (6 страниц)
- **assets/** — Стили и скрипты
- **config/** — База данных
- **protected/** — Авторизация

## Особенности

- Ролевая модель (админ/преподаватель/студент)
- Синхронизация данных между вкладками
- Панель доступности для людей с ОВЗ
- Bootstrap 5.3
