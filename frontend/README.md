# Учеба24 — Студенческий компас

Простая платформа для студентов колледжа Калининграда.

## Быстрый старт

1. **Импортируйте БД:**
```bash
mysql -u root -p < frontend/database/full_database.sql
```

2. **Откройте в браузере:**
```
http://studapp.local/
```

## Тестовые аккаунты

| Роль | Логин | Пароль |
|------|-------|--------|
| Админ | admin | admin123 |
| Преподаватель | teacher1 | teacher123 |

## Структура

```
frontend/
├── index.php              # Главная
├── dashboard.php          # Вход
├── register_new.php       # Регистрация
├── auth.php               # Обработка входа
├── reg_process.php        # Обработка регистрации
├── logout.php             # Выход
├── config/db.php          # БД + функции
├── includes/header.php    # Шапка
├── includes/footer.php    # Подвал
├── student/               # Страницы студентов
├── admin/                 # Админ-панель
├── teacher/               # Преподаватели
├── assets/css/style.css   # Стили
├── assets/js/             # JavaScript
└── database/full_database.sql
```

## Функции

- Библиотека работ (скачивание)
- Карта campus (Leaflet)
- Отзывы о преподавателях
- Советы от выпускников
- Расписание
- Оценки и посещаемость

## Роли

- **Гость** — главная, вход, регистрация
- **Студент** — библиотека, карта, отзывы, советы, оценки
- **Преподаватель** — журнал, расписание, проверки
- **Админ** — управление пользователями
