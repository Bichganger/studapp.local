## 💡 Особенности реализации:

### Трехуровневая система:
```
1. API (БД) - приоритет
2. localStorage - если API недоступен
3. MOCK данные - если localStorage пуст
```

### Пример:
```javascript
// Получение расписания
const schedule = await Sync.getSchedule();
// → пробует api/sync.php?action=get_schedule
// → если ошибка: пробует localStorage
// → если пусто: возвращает MOCK_DATA.schedule
```

### Добавление данных:
```javascript
// Добавление оценки
await Sync.addGrade({student_id: 4, subject: 'Математика', grade: '5'});
// → отправляет в API
// → сохраняет в localStorage
// → показывает уведомление
```
