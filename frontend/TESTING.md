## 🐛 Частые проблемы

### "Ошибка подключения к БД"
```bash
# Проверьте config/db.php
# Убедитесь что studapp существует
mysql -u root -p -e "SHOW DATABASES;"
```

### "API не отвечает"
```bash
# Проверьте api/sync.php
chmod 644 frontend/api/sync.php
```

### "Данные не сохраняются"
- Очистите localStorage: `localStorage.clear()`
- Проверьте Network tab на ошибки
- Убедитесь что PHP сервер запущен

### "Не вижу свои данные"
- Проверьте group_name в БД
- Убедитесь что role правильный
- Проверьте WHERE условия в SQL
