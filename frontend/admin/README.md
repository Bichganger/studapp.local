# Админ-панель Учеба24 - Документация

## Реализованные функции

### 1. Главная панель (admin-dashboard.php)
- **Статистика пользователей**: Отображение общего количества пользователей, студентов и преподавателей из базы данных
- **Быстрый доступ**: Карточки-ссылки на все разделы админ-панели
- **Живой фон**: Нейронная анимация (используется neural-network.js)

### 2. Управление пользователями (admin-users.php)
**Реализованные функции:**
- ✅ Просмотр списка всех пользователей с информацией (ФИО, логин, роль, дата регистрации)
- ✅ Добавление нового пользователя (ФИО, логин, пароль, роль)
- ✅ Удаление пользователя (с защитой от удаления собственного аккаунта и других администраторов)
- ✅ Статистика по пользователям (всего, студенты, преподаватели)
- ✅ Валидация данных на сервере
- ✅ Проверка на занятость логина
- ✅ Хэширование паролей (password_hash)

**API:** Встроен в PHP файл (обработка POST/GET запросов)

### 3. Управление расписанием (admin-schedule.php)
**Реализованные функции:**
- ✅ Форма добавления новой пары (день, группа, предмет, время, тип, аудитория, преподаватель)
- ✅ Таблица текущего расписания с данными из БД
- ✅ Редактирование существующих пар
- ✅ Удаление пар
- ✅ Экспорт расписания в CSV формат
- ✅ Автоматический расчет времени конца пары (90 минут)
- ✅ Сортировка по дням недели и времени
- ✅ Динамическое обновление списка групп

**API:** `api/schedule.php`
- GET - получение расписания (с фильтрами по дню и группе)
- POST - добавление пары
- PUT - обновление пары
- DELETE - удаление пары

**База данных:** Таблица `schedule` создается автоматически

### 4. Управление группами (admin-groups.php)
**Реализованные функции:**
- ✅ Форма создания новой группы (название, специальность, курс, количество студентов, зав. кафедрой)
- ✅ Отображение карточек всех групп
- ✅ Просмотр详细信息 группы (модальное окно)
- ✅ Редактирование группы
- ✅ Удаление группы (с подтверждением)
- ✅ Цветовое кодирование групп

**API:** `api/groups.php`
- GET - получение списка групп
- POST - создание группы
- PUT - обновление группы
- DELETE - удаление группы

**База данных:** Таблица `study_groups` создается автоматически

### 5. Библиотека работ (admin-library.php)
**Реализованные функции:**
- ✅ Статистика работ (на проверке, одобрено, отклонено)
- ✅ Фильтрация по предмету, типу работы, статусу
- ✅ Отображение работ с статусом "pending" для модерации
- ✅ Одобрение работы (изменение статуса на "approved")
- ✅ Отклонение работы (изменение статуса на "rejected")
- ✅ Удаление работы
- ✅ Скачивание файлов работ
- ✅ Просмотр详细信息 работы (модальное окно)

**API:** `api/library.php`
- GET - получение работ (с фильтрами)
- POST ?action=approve - одобрение работы
- POST ?action=reject - отклонение работы
- DELETE - удаление работы

**База данных:** Таблица `library_works` создается автоматически

### 6. Рассылка уведомлений (admin-notifications.php)
**Реализованные функции:**
- ✅ Форма отправки уведомления (получатели, тема, текст)
- ✅ Выбор целевой аудитории (все, студенты, преподаватели, конкретная группа)
- ✅ Опция отправки на email
- ✅ История отправлений с статусами
- ✅ Просмотр详细信息 уведомления
- ✅ Автоматическое обновление истории

**API:** `api/notifications.php`
- GET - получение истории уведомлений
- POST - отправка нового уведомления
- PUT ?action=view - просмотр уведомления

**База данных:** Таблица `notifications` создается автоматически

### 7. Настройки системы (admin-settings.php)
**Реализованные функции:**
- ✅ Общие настройки (название системы, email, часовой пояс, режим обслуживания)
- ✅ Настройки регистрации (открытая регистрация, подтверждение email, мин. длина пароля)
- ✅ Настройки уведомлений (email/SMS, SMTP сервер и порт)
- ✅ Настройки безопасности (время сессии, максимум попыток, блокировка, 2FA)
- ✅ Сохранение всех настроек в БД
- ✅ Автоматическая загрузка сохраненных настроек при открытии страницы

**API:** `api/settings.php`
- GET - получение всех настроек
- POST - сохранение настроек (JSON формат)

**База данных:** Таблица `system_settings` создается автоматически

## Требования

- PHP 7.4+
- MySQL 5.7+ / MariaDB 10.2+
- PDO extension enabled
- Bootstrap 5.3 (CDN)
- Bootstrap Icons (CDN)

## Безопасность

- Проверка роли администратора в каждом файле
- Prepared statements для всех SQL запросов
- Хэширование паролей (password_hash)
- Защита от SQL инъекций
- XSS защита (htmlspecialchars)
- CSRF защита (session-based)

## Установка

1. Убедитесь, что таблицы `users` уже существуют
2. API автоматически создаст недостающие таблицы при первом запуске
3. Убедитесь, что у PHP есть права на подключение к БД

## Примечания

- Все изменения сохраняются в базе данных
- JavaScript обеспечивает динамическое обновление без перезагрузки страницы
- Используется RESTful API для коммуникации
- Все ответы в формате JSON
- Уведомления об ошибках/успехе показываются в виде Bootstrap alerts
