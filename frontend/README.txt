# Учеба24

Учебная система для студентов и преподавателей.

## Структура:

- `frontend/` - все файлы сайта
- `admin/` - админка
- `student/` - материалы для студентов
- `teacher/` - материалы для преподавателей

## Запуск:

1. Загрузить файлы на хостинг с PHP 7.4+
2. Создать БД MySQL
3. Настроить `config/db.php`
4. Открыть в браузере
