### 3. Синхронизация через БД

**sync.js работает так:**
1. ✅ Сначала пытается получить данные из БД (api/sync.php)
2. ✅ Если БД недоступна — использует localStorage
3. ✅ Если localStorage пуст — использует MOCK_DATA

**Все данные синхронизируются между пользователями:**
