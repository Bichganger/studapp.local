# 🧠 ЖИВАЯ НЕЙРОСЕТЬ ЗНАНИЙ
## Уникальная визуальная система проекта Учеба24

---

## 🎯 Концепция

**Живая Нейросеть Знаний** — это инновационная визуальная система, которая делает платформу Учеба24 уникальной и запоминающейся.

### Основные элементы:

1. **Анимированный фон с частицами**
2. **Интерактивные связи между узлами**
3. **Персонализация под роль пользователя**
4. **Глассморфизм карточки**
5. **Умные приветствия**

---

## ✨ Визуальные особенности

### 🎨 Цветовые схемы по ролям

| Роль | Цветовая гамма | Описание |
|------|----------------|----------|
| **Студент** | `#667eea → #764ba2` | Фиолетовый градиент |
| **Преподаватель** | `#f093fb → #f5576c` | Розово-красный градиент |
| **Администратор** | `#4facfe → #00f2fe` | Голубой градиент |

### 🌊 Эффекты

- **Живой градиент** — плавная анимация фона (15 секунд)
- **Частицы нейросети** — интерактивные узлы, реагирующие на мышь
- **Глассморфизм** — полупрозрачные карточки с размытием
- **Параллакс** — 3D эффект при движении мыши
- **Конфетти** — праздничный эффект при успехе

## 🚀 Как подключить

### 1. Добавить CSS
```html
<link rel="stylesheet" href="css/neural-network.css">
```

### 2. Добавить фон
```html
<div class="neural-bg"></div>
<canvas id="neuralNetworkCanvas"></canvas>
```

### 3. Инициализировать JS
```html
<script src="js/neural-network.js"></script>
```

### 4. Добавить класс роли
```html
<body class="role-student">  <!-- или role-teacher, role-admin -->
```

## 🎨 Кастомизация

### Изменить цвета
```css
/* В css/neural-network.css */
.role-student .neural-bg {
    background: linear-gradient(135deg, ВАШИ_ЦВЕТА);
}
```

### Настроить частицы
```javascript
// В js/neural-network.js
const particleCount = 80;  // Количество частиц
const maxDistance = 150;   // Дистанция связей
```
