## 🚀 Как запустить

1. **Импортируйте БД:**
```bash
mysql -u root -p studapp < frontend/database/full_database.sql
```

2. **Откройте в браузере:**
```
http://localhost/frontend/
```

3. **Войдите:**
- Главная → Войти
- Используйте любые тестовые данные выше

4. **Проверьте синхронизацию:**
- Админ → Пользователи → Добавить
- Преподаватель → Оценки → Добавить
- Студент → Работы → Загрузить
- Все данные сохраняются в БД через API

## 🔄 Взаимодействие между ролями

1. **Admin создает пользователя** → Студент видит себя в системе
2. **Admin создает группу** → Преподаватель видит группу
3. **Teacher выставляет оценку** → Студент видит оценку
4. **Student сдает работу** → Teacher видит на проверку
5. **Admin отправляет уведомление** → Все получают
6. **Teacher ведет журнал** → Студент видит посещаемость

Все через единую БД с синхронизацией!
