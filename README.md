# Учеба24 — Студенческий компас

Платформа для студентов колледжа: расписание, оценки, библиотека, отзывы о преподавателях.

## Быстрый старт

### Требования
- PHP 8.0+
- MySQL 8.0+
- Веб-сервер (Apache/Nginx)

### Установка

1. Создайте БД `studapp`
2. Импортируйте `database/studapp.sql`
3. Запустите миграции из `scripts/`
4. Откройте `http://studapp.local`

## Тестовые учётные записи

| Логин | Пароль | Роль |
|-------|--------|------|
| admin | admin123 | Администратор |
| teacher1 | teacher123 | Преподаватель |
| student1 | student123 | Студент |

## Структура

- `admin/` — Админ-панель
- `student/` — Кабинет студента
- `teacher/` — Кабинет преподавателя
- `config/` — Конфигурация
- `scripts/` — Миграции и утилиты
- `database/` — SQL файлы
- `docs/` — Документация
- `assets/` — CSS/JS
- `uploads/` — Загрузки
