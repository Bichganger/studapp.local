|------|----------|

## Структура проекта

```
studapp.local/
├── admin/              Админ-панель
├── student/            Кабинет студента
├── teacher/            Кабинет преподавателя
├── config/             Конфигурация
├── scripts/            Миграции и утилиты
├── database/           SQL файлы
├── docs/               Документация
├── assets/             CSS/JS
├── includes/           Общие компоненты
├── protected/          Защита
├── uploads/            Загруженные файлы
├── index.php           Главная
├── dashboard.php       Вход/регистрация
├── auth.php            Обработчик входа
├── register_new.php    Регистрация
└── logout.php          Выход
```
